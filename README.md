# TournamentLib

Build and run your tournaments with ease.

[![AGPL License](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](LICENSE)

## Overview

TournamentLib is a TypeScript library focused on tournament flow management.

It is designed to help you:

- create tournament of one or two phases
- score matches
- progress brackets automatically
- compute results and rankings

## Current Features

- Duel format
  - progression logic
  - Single and double elimination modes
  - Extended finals support
  - Forfeit and walkover handling
  - Match, set, and opponent telemetry
- Strict TypeScript-first API

## Project Status

Early version, actively evolving.

Short-term roadmap:

- Round Robin format
- Free-for-all format
- Tournament orchestration (multi-phase, multi-format)
- Documentation and examples
